Spaceship Titanic

Passenger transportation prediction using tree-based classification models.

Best result: 78.18% validation accuracy after LightGBM hyperparameter tuning and probability threshold optimization.
Selected threshold: 0.42

1. Dataset

The project uses the Kaggle Spaceship Titanic dataset. The training data contains 8,693 rows and 14 columns, while the test data contains 4,277 rows and 13 columns.

The target variable is Transported, which represents whether a passenger was transported.

2. Data Preprocessing

The original dataset contained categorical, numerical and high-cardinality features.

Missing Values

  • Categorical columns were filled with Unknown.
  • Numerical columns were filled using the median.
  • Rows with remaining missing values in the training data were removed.

Removed Features

  • Cabin was removed because cabin information was shared by passengers.
  • Name was removed because most names were unique and unlikely to generalize.

The categorical features were converted into numerical dummy variables using one-hot encoding.

Final model features included passenger age, spending in Room Service, Food Court, Shopping Mall, Spa and VR Deck, along with encoded Home Planet, CryoSleep, Destination and VIP information.

4. Hyperparameter Tuning

Gradient Boosting was first tuned using GridSearchCV. The best cross-validation accuracy was approximately 80.23%, but its validation accuracy was approximately 77.15%.

LightGBM was then tuned using RandomizedSearchCV with 30 parameter combinations and 5-fold cross-validation.

The best LightGBM parameters were:

{
    "subsample": 1.0,
    "reg_lambda": 0.1,
    "reg_alpha": 0.0,
    "num_leaves": 31,
    "n_estimators": 100,
    "min_child_samples": 20,
    "max_depth": -1,
    "learning_rate": 0.05,
    "colsample_bytree": 1.0
}

The best cross-validation score was approximately 80.49%, with a validation accuracy of 77.84%.

5. Classification Threshold

Instead of directly using the default probability threshold of 0.50, prediction probabilities were obtained using predict_proba(). 

probs = model.predict_proba(X_val)[:, 1]

Thresholds from 0.01 to 0.99 were tested. The threshold producing the highest validation accuracy was:

Threshold = 0.42
Validation Accuracy = 78.18%

The final binary prediction is therefore based on whether the probability of Transported = True is at least 0.42. 

predictions = test_probs >= 0.42

6. Final Prediction

The tuned LightGBM model was used to generate probabilities for the test dataset. The optimized threshold was then applied to convert those probabilities into True/False predictions.

The resulting predictions were combined with PassengerId and saved as: 

./cdata/predictions.csv

7. Final Pipeline

The overall workflow was:

  1. Load the Spaceship Titanic dataset.
  2. Analyze missing values and feature types.
  3. Handle categorical and numerical missing values.
  4. Remove Cabin and Name.
  5. One-hot encode categorical features.
  6. Compare multiple tree-based classifiers.
  7. Tune Gradient Boosting and LightGBM.
  8. Select the best LightGBM model.
  9. Optimize the classification threshold.
  10. Generate test predictions.
  11. Save predictions to CSV.
