Project Overview

This project processes the Brazilian E‑Commerce (Olist) dataset through a complete ETL pipeline: loading 9 CSV files, validating primary keys, handling nulls, merging via a star‑schema, and engineering features for a LightGBM classifier. The trained model is converted to ONNX and deployed in the browser using ONNX Runtime Web for real‑time inference.

Model Training & ONNX Export
LightGBM Classifier
  • Features: price, freight_value, payment_installments, payment_value, review_score, on_time_delivery, approval_time, demand_category, review_response_time
  • Target: order_status (binary: delivered vs others)
  • Training rows: 117,314
  • Validation: 80/20 split
  • Metrics: Accuracy ~ 0.96, F1 ~ 0.94
ONNX Conversion

Using onnxmltools, the trained LightGBM model was exported to ONNX format:

import onnxmltools
from onnxmltools.convert.common.data_types import FloatTensorType

initial_type = [('float_input', FloatTensorType([None, X_train.shape[1]]))]
onnx_model = onnxmltools.convert_lightgbm(
    final_model, initial_types=initial_type
)
onnxmltools.utils.save_model(onnx_model, 'lgbm_model.onnx')
