📌 Executive Summary

This project builds a robust customer satisfaction classifier for Brazilian e‑commerce orders. Using the Olist dataset, we integrated 9 tables, engineered 34 predictive features, and trained a LightGBM model with Optuna hyperparameter tuning.

The final leakage‑free model achieves a ROC‑AUC of 0.8057 and accuracy of 84%, with excellent recall (0.93) for satisfied customers. The optimal decision threshold is 0.666.

The model is exported to ONNX for easy integration into production systems (available in the repository).

🔗 Table Relationships & Joins

The data model follows a star‑like schema with orders as the central table.

Join Conditions:

  • • customers.customer_id = orders.customer_id
  • • orders.order_id = order_items.order_id
  • • orders.order_id = order_payments.order_id
  • • orders.order_id = order_reviews.order_id
  • • order_items.product_id = products.product_id
  • • order_items.seller_id = sellers.seller_id

📌 Conclusion

This project successfully built a robust LightGBM classifier for predicting customer satisfaction in Brazilian e‑commerce, achieving a ROC‑AUC of 0.8057 and accuracy of 84%. The model uses 34 leakage‑free features, with top drivers including product_category_name, payment_value, price, customer_state, and delay_severity.

The ONNX export enables easy integration into production systems, and the entire pipeline is reproducible via the provided notebooks. Future work could include seller performance metrics, geographical distance, and exploring alternative algorithms like XGBoost or TabNet.

Next steps: deploy the ONNX model as a microservice, add real‑time feature extraction, and monitor model drift.
