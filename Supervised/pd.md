# 📊 Brazilian E-Commerce Public Dataset by Olist

## Project Overview

This is a **comprehensive Brazilian e-commerce dataset** containing **100,000 orders** from 2016 to 2018 made at the Olist Store across multiple marketplaces in Brazil.

---

## 🎯 Key Highlights

| Feature | Description |
|---------|-------------|
| **Orders** | 100,000+ transactions |
| **Time Period** | 2016 - 2018 |
| **Data Type** | Real commercial data (anonymized) |
| **License** | CC BY-NC-SA 4.0 |
| **Popularity** | 2.43M views, 618K downloads |

---

## 📁 Dataset Structure (9 Files)

```
├── olist_customers_dataset.csv      # Customer info & location
├── olist_geolocation_dataset.csv    # Zip code → lat/lng mapping
├── olist_order_items_dataset.csv    # Items per order
├── olist_order_payments_dataset.csv # Payment details
├── olist_order_reviews_dataset.csv  # Customer reviews
├── olist_orders_dataset.csv         # Order status & dates
├── olist_products_dataset.csv       # Product attributes
├── olist_sellers_dataset.csv        # Seller information
└── product_category_name_translation.csv # Category names (Portuguese → English)
```

---

## 🌟 Interesting Facts

- **Customer IDs** are unique per order — same customer gets different IDs for different orders
- **`customer_unique_id`** allows tracking repeat customers
- **Store/partner names** replaced with *Game of Thrones* house names
- **One order can have multiple items** from different sellers
